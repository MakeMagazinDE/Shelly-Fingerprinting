# Geräte-Fingerprinting mit gehacktem Shelly

### Mit eigener Firmware liefert ein Shelly EM Gen3 über 2000 Messungen pro Sekunde statt einer einzigen.

Damit lässt sich jeder Maschine in der Werkstatt ein elektrischer Fingerabdruck abnehmen. Ein lernfähiges Ratespiel erkennt an einem einzigen Messpunkt, welches Werkzeug gerade läuft.

![Picture](https://github.com/MakeMagazinDE/Shelly-Fingerprinting/blob/master/Shelly-Fingerprinting.jpg)

Den vollständigen Artikel mit der Bauanleitung gibt es in der [Make-Ausgabe 6/26 ab Seite XX](https://www.heise.de/select/make/2026/6). Hier finden Sie die Firmware für den Shelly EM Gen3, den Logger und die Auswerteskripte für den PC sowie das Ratespiel, eine Kurzanleitung steht in [ANLEITUNG.md](ANLEITUNG.md).
